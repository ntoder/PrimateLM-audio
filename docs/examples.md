# Examples

Real clips from the **test set** (audio the model never saw during training). Each card shows the audio, its spectrogram, the true label, and what the model predicted. We include mistakes on purpose — they show where the model struggles.

!!! info "Filled in after training"
    These cards are generated automatically by `model/make_examples.py` after training (build step 3). No example on this page is hand-picked to look good: the script takes the first correct and first incorrect test clip per class.
