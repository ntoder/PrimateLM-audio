# Team

PrimateLM-audio is built by a school robotics team.

| Role | What they do |
|---|---|
| Data | Finds and checks datasets and licenses; runs the download script. |
| Model | Trains and evaluates the classifier; writes up the results honestly. |
| Demo | Builds and deploys the Gradio web demo. |
| Robot | Runs the live detector on the Raspberry Pi and connects it to the robot. |
| Docs | Keeps this site up to date. |

!!! tip "Add yourselves"
    Edit `docs/team.md` to add each member's name next to their role.
